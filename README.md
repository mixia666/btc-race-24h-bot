A momentum-confirmed trend-hold bot for cbBTC/USDC on the make.fun bars-replay protocol: it enters only after the close has risen at least 0.3% over the trailing 90 one-minute bars, stakes 99% of its cash once, rides the trend without churning, and exits the whole position if the close falls 2.5% below its peak since entry.

## Run it

```sh
node main.ts
```
